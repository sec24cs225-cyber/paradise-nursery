# Paradise Nursery

## Project Name
Paradise Nursery

## Project Description
Paradise Nursery is a responsive React plant-shopping application. Users can explore plants, view product information, add plants to a shopping cart, change quantities, remove items, and view the cart total.

## Technologies Used
- React
- JavaScript
- Redux Toolkit
- React Redux
- CSS
- Vite

## Main Features
- Paradise Nursery landing page
- Get Started button
- About Us information
- Plant product listing
- Add to Cart functionality
- Shopping cart
- Increase/decrease quantity
- Remove products
- Automatic cart totals
- Responsive design

## How to Run
1. Install Node.js.
2. Open this project folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.
